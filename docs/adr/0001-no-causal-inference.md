# ADR-0001: 不做因果推断

## 状态
Accepted

## 背景
项目目标是解释月度 GMV 环比异动。"为什么会跌"在严格意义上是因果问题，需要反事实（counterfactual）或干预变量（treatment）来识别因果效应。

Olist 公开数据集只有交易/评价/商品/卖家/地理位置等观测性字段，没有任何干预变量（促销、价格调整动作、物流政策变更）、没有对照组、没有时间上对齐的外部事件标记。

## 决策
本项目**显式不做因果推断**。所有产出按强度分三层：
- 因素分解（数学恒等式，可对账）
- 各维度贡献（描述性归因，可对账）
- LLM 定性假设（明确标注为假设，非结论）

报告中凡涉及"原因"的表述，一律使用"假设/可能"措辞，不使用"导致/因为"等因果断言。

## 替代方案
- 引入因果推断（DiD、合成控制等）：数据缺关键变量，结论不可信，反而误导。
- 模糊处理、让 LLM 直接断言根因：当前旧版脚本的做法，等于用相关冒充因果，是本项目要修正的核心问题。

## 后果
分析"深度"靠因素分解与贡献分析的量化严谨度支撑，而非因果主张。未来若接入干预数据（促销日志、A/B 实验），可单独引入因果层。
