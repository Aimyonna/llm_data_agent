# ADR-0002: LLM 只做假设生成，不做分析引擎

## 状态
Accepted

## 背景
旧版 `auto_analyzer.py` 把异动月的差评塞给 LLM 做"人/货/场"聚类，并直接在报告里当作"暴跌根因"输出。问题：
1. LLM 在脚本里扮演了"分析引擎"，但其产出不可复算、不可对账、随模型/温度变化。
2. 差评与下跌同月发生，是症状不是被证明的原因——LLM 把相关包装成因果。

## 决策
LLM 的角色降级为**定性假设生成器**：
- **输入**：Python 量化引擎产出的 PVM 三因子、品类/地区/Seller 贡献、评论主题词。
- **输出**：用业务语言把这些量化发现串成解释性假设 + 运营建议，**明确标注为假设**。
- LLM 不做任何统计计算，不替代因素分解，不单独断言根因。

量化严谨度由 Python 侧的 PVM 与贡献分析承担；LLM 只负责把数字翻译成业务叙事。

## 替代方案
- 维持旧版 LLM 自动归因：不可复算、过度主张，是本项目要修正的核心问题。
- 完全去掉 LLM：失去把量化结果翻译成业务语言的能力，报告对运营不友好。

## 后果
Pipeline 中 LLM 步骤从"分析核心"变为"末端叙事层"。LLM 失败时脚本优雅降级（仅缺假设段），量化分析与报告照常产出。
